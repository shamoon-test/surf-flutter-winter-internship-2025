# Отчёт о проделанной работе

## Общая информация

В рамках стажировочного задания было разработано Flutter-приложение,
реализующее функциональность согласно техническому заданию. Основной фокус чистая архитектура, предсказуемое управление состоянием и аккуратная структура проекта.

## Архитектура проекта

Проект построен по схеме **data → domain → presentation**, без выделения фич-модулей - это оптимально для небольших приложений:

-   **data** DTO-модели, источники данных, репозитории, реализация
    работы с локальной базой
-   **domain** Сущности, абстрактные репозитории, use-cases
-   **presentation** UI, BloC-логика, экраны, виджеты

## Использованные технологии

-   **Flutter**
-   **BLoC**
-   **get_it**
-   **retrofit + dio**
-   **Localstore**
-   **go_router**
-   **build_runner**

## Запуск проекта

Перед запуском необходимо выполнить генерацию:

``` sh
flutter pub get
```

``` sh
flutter pub run build_runner build --delete-conflicting-outputs
```

``` sh
flutter run
```

## Структура проекта

    lib/
    │
    ├── api/    -   модуль с сетевыми запросами: Retrofit-клиент, модели ответа, вспомогательные классы.
    │
    ├── core/
    │   ├── app/    -   MaterialApp с глобавльными провайдерами блоков
    │   ├── di/ -   сервис локатор с DI
    │   └── router/ -   роутер с роутами и нижнее меню приложения
    │
    ├── data/
    │   ├── datasources/
    │   ├── dto/    -   объекты которые пишутся в БД и извлекаются из нее
    │   ├── repositories/   -   реализация репозиториев
    │   └── mappers/    -   маппер для преобразования из апи в dto
    │
    ├── domain/
    │   ├── entities/   -   сущности для работы бизнес-логики
    │   ├── repositories/   -   интерфейсы репозиториев
    │   └── usecases/   -   варианты использования
    │
    ├── presentation/
    │   ├── bloc/   -   стейт менеджеры (bloc'и и cubit'ы)
    │   ├── pages/  -   страницы приложения
    │   └── widgets/ - отдельные виджеты - карточки фруктов, рецептов, кнопки избранного и т.д.
    │
    └── main.dart   -   точка старта приложения
